# Prompt Reviewer

**ARC Labs** — Free · Open Source · Community Project

Paste a system prompt and get a structured review: clarity, ambiguity, injection surface, failure modes, and concrete rewrites — the review a senior engineer would give, minus the wait.

> Code lives in this Google Drive ARC Labs folder and in the GitHub repo. Sister tool: [MCP Conformance Scanner](https://github.com/aking-beep/mcp-conformance-scanner).
